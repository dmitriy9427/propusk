# 01. Обзор и запуск

## Что умеет

- **Регистрация** с подтверждением почты (письма — во встроенной демо-почте).
- **Вход по паролю** с защитой от перебора: одинаковая ошибка для «нет почты» и «неверный
  пароль», блокировка после пяти неудач с растущей паузой.
- **Токены:** access на 10 минут в памяти, refresh на 30 дней в HttpOnly-cookie,
  ротация при каждом обновлении и обнаружение кражи.
- **Двухфакторная защита:** код из приложения-аутентификатора, QR-код, 10 кодов восстановления.
- **Ключи доступа (passkeys):** вход отпечатком или лицом, без пароля.
- **Вход через «Ромашка ID»** — демо-провайдер с настоящим OAuth 2.0 + PKCE + OpenID Connect.
- **Вход по ссылке** из письма и **сброс пароля**.
- **Устройства:** список сессий, завершить одну или все другие.
- **Режим судо:** смена пароля, выключение 2FA и удаление ключей — только после повторного
  подтверждения личности.
- **Роли:** администратор блокирует пользователей и меняет роли.
- **Журнал событий** безопасности.
- **«Под капотом»:** расшифровка токена, «испортить токен», «украсть refresh-токен» — по шагам.

## Два режима

| Режим | Команды | Сервер | Cookie |
| --- | --- | --- | --- |
| Демо (как на GitHub Pages) | `npm run dev` | в браузере, через MSW | изображаются (MSW хранит их в localStorage) |
| Настоящий | `npm run server` и `npm run dev:real` | Node на порту 8787 | настоящие HttpOnly |

Код сервера в обоих режимах **один и тот же** — [глава 10](10-server.md).
