# Учебник по «Пропуску»

Авторизация — тема, где «работает» и «безопасно» — разные вещи. Форму входа можно
написать за вечер, и она будет пускать по паролю. А потом выяснится, что пароли лежат в
базе открытым текстом, токен можно украсть одной строкой JavaScript, а ссылка «сбросить
пароль» работает вечно.

Этот учебник разбирает, **как сделать вход правильно** и **почему каждая деталь именно
такая**. Каждая глава устроена одинаково: зачем → простой пример → как сделано в
«Пропуске» (код по частям) → атаки и ошибки → попробуйте сами.

## Как учиться

1. Откройте демо, войдите как Анна и зайдите на страницу **«Под капотом»**. Там можно
   увидеть токен, испортить его и украсть refresh-токен — и посмотреть, как срабатывает защита.
2. Откройте DevTools → Network и пройдите вход администратора (пароль + код). Сравните
   запросы с [главой 05](05-two-factor.md).
3. Читайте главы по порядку: каждая опирается на предыдущие.
